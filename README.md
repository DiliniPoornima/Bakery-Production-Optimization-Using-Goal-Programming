# Bakery Production Optimization Using Goal Programming

## Project Overview
This project focuses on optimizing production planning and profitability for Food Art (Pvt) Ltd, a bakery products company, using Goal Programming techniques.

The study uses real-world production and cost data to develop a mathematical optimization model that supports effective production decisions.

## Objectives
- Achieve a minimum weekly profit target.
- Maintain production costs within the specified budget.
- Minimize overtime requirements for packing and baking.
- Determine optimal weekly production quantities for bread and buns.

## Methodology
- Collected and analyzed production and operational cost data.
- Formulated a Goal Programming model with multiple prioritized objectives.
- Applied Linear Programming techniques to solve the optimization problem.
- Implemented the mathematical model using MATLAB's `linprog` function.
- Evaluated optimization results to support production planning decisions.

## Tools and Technologies
- MATLAB
- Goal Programming
- Linear Programming
- Mathematical Optimization
- Operations Research

## Project Outcome
The MATLAB optimization model produced a solution recommending approximately 113,235 buns per week and no bread production under the formulated constraints. This result illustrates how mathematical optimization can support business decision-making.
